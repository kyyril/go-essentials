# Go Essentials

A collection of Go code snippets, core concepts, design pattern implementations, and practical utilities.

## Overview

This repository serves as a personal reference and playground for learning and practicing Go concepts, ranging from fundamental language features to architecture patterns and mini-projects.

## Directory Structure

```text
go-essentials/
├── any/               # Generic types and stack strategy implementations
├── cache/             # Fibonacci memoization and cache examples
├── map/               # Map counting and grouping demos
├── oop / solid/       # SOLID principles examples and object-oriented paradigms
├── task-api/          # Task controller API implementation with Swagger documentation
├── test/              # Utility functions and test suites (e.g., palindrome checker)
├── *.go               # Core root examples (context, error handling, goroutines, HTTP server, pointers, structs)
